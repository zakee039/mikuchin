世界书

为当前角色提供按需触发的背景资料

手动条目关键词命中或常驻时注入上下文
Markdown 资料读取本机文件，不修改原文

支持本机绝对路径及 OneDrive 已同步目录，可递归检索 .md 文件；默认不启动第二个模型。

修改完成后点击上方「保存设置」。世界书仅在相关时注入，不影响角色的基本身份。

工作流
