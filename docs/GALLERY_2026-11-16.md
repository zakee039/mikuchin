# Mikuchin 画廊第一版（2026-11-16）

## 交互
- 顶部原「图像」改为「生图」，旁边新增「画廊」。
- 按来源全部、生图、聊天、本地模型、API 筛选，支持最新/最旧排序；默认加载 60 张，可继续加载。
- 点击缩略图放大，键盘 ← → 切换、Esc 关闭；移动端可左右滑动。
- 右上角 NSFW 默认关闭，已标记作品模糊；大图可临时查看单张、手动设置或取消 NSFW 标记。
- 多选模式提供全选已加载、取消选择与批量永久删除；提示聊天中的历史图片链接可能失效。

## 索引与存储
- chat/gallery-index.sqlite3：持久化 SQLite 索引，仅收录 chat/generated-images 目录下随机 32 位十六进制名称的 PNG。
- chat/gallery-thumbnails：持久 JPEG 缩略图缓存（最大 420px）。
- 首次画廊访问补扫历史 PNG。后续生图成功直接写索引；手动刷新可补扫和修复。每次读取仅校验索引文件存在性，不全目录重扫。
- 历史聊天图片根据保存的工具消息及 recent_generated_images 尝试识别来源；无法判定的历史图归「生图」且不猜测缺失的 Prompt/模型。
- 生图页本地/API、聊天工具本地/API 四类成功路径都接入索引写入；超分原图与输出均可查看。

## NSFW / 数据保护
- 模型名包含 uncensored 的图片初始遮罩，其他默认不标记；它只是启发式标签，可能误判，可手动修正。
- 模糊是浏览器展示效果，不是磁盘加密/视觉识别/网络访问控制。
- GET /v1/mikuchin/gallery 需要已配置的 API Key，POST 要求已授权的本应用会话；大图沿用原有随机文件名能力 URL，缩略图通过随机图片 ID 读取。
- 删除只接受已索引的随机图片 ID，最多一次 150 张；永久删除原 PNG、缓存与索引行，不进入用户上传目录、角色目录或 KV 目录。
- 删除仍被聊天引用的图片后，历史会话中的引用会失效。需要确认，且不支持回收站。
- 版本号不变，未提交 GitHub、Tag 或 Release。


## 2026-11-16 画廊分组与管理增强
- 有 `parent_id` 关联的 4× 超分结果和原图在画廊合并为一张卡片，默认显示超分后的图像。左上角显示带阴影的份数徽标（例如 2）。源文件保持两份，索引不做缩略图推断。
- 分页、来源筛选与数量统计按作品组计算；历史 17 个文件里找到 7 组已建立的原图/超分关系，因此应呈现 10 张卡片。
- 多选栏新增「标记为NSFW」，一次作用于所有选中作品及其原图/超分图。单张详情修改 NSFW 也联动该组全部变体。
- 作品详情新增「删除原图」「删除4×」两个仅在成对作品上显示的按钮：删除原图后保留 4× 图；删除 4× 图后将原图晋升为独立作品，保留手动 NSFW 设置。
- 详情普通删除、多选删除仍按整组处理，连同原图、超分图和缩略图一起删除，并明确提示聊天中的图片链接可能失效。
- API 增加 `nsfw_many`、`delete_variant` 动作；删除限定索引中的合法图片 ID，最大每批 150 组，前端对大量选择分批处理。
- 修改仅作用于画廊索引与前后端展示，未主动删除任何用户图片。
