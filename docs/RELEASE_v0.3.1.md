# Mikuchin v0.3.1 — Image Task Retry Cleanup

2026-11-19 · Main **0.3.1** / Windows Launcher **0.3.0**（沿用）/ Android **0.3.0**，versionCode **300**（沿用）。

## 本次行为调整

- **失败任务的重试**：先验证原请求、参考图和队列容量，然后在同一个 SQLite 事务里创建新 `running` 任务并删除原 `failed` 任务；返回新任务 ID 和 `deleted_original_id`，页面立即移除旧失败任务。无论新任务随后成功还是再次失败，都不重新显示原失败记录。
- **成功任务的重试**：沿用旧行为；成功记录保留，创建新的独立任务。
- **未成功提交**：参数无效、无参考图、任务队列已满时不会删除失败任务，不触发重复请求。
- **用户资产**：销毁的仅是原失败任务记录；画廊图片不被删除，重试任务引用的参考图继续保留。再次失败的任务仍可继续重试。
- 网页脚本缓存版本更新，以确保客户端刷新后加载新逻辑。

## 版本控制与验证

- `versions.json` 是唯一版本号来源，执行 `scripts/versioning.py sync` + `check`。
- 后端生图任务回归、前端任务按钮交互测试需通过，特别是失败源任务的原子替换、引用图保留、重试失败不删除、成功源任务继续保留。
- 本次不做原生 PolyStrata/Gateway 迁移，不碰旧对话和用户数据，不自动发起实际付费生成。
- 不重建启动器和 APK；已运行的主程序需在无活动任务时安全重启使后端更新生效。
- Git 提交与 GitHub Release 不等价，正式发布状态应以实际 GitHub 发布为准。
