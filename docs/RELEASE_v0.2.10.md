# Mikuchin v0.2.10 — Desktop-owned Image Jobs & Mobile Gallery

2026-11-19 · Main 0.2.10 / Launcher 0.2.10 / Android 0.2.10 (versionCode 210)

## 核心改动

- **生图彻底脱离浏览器保活**：生图工作台和画廊的 4x 超分均使用服务端任务队列，提交立即返回任务 ID，浏览器关闭不取消工作。聊天内由 `polystrata__generate_image` 触发的本地/在线生图同样在 desktop 后台执行，任务与客户端 HTTP 连接分离。
- **聊天会话结果恢复**：任务状态与产物索引落在桌面 SQLite；即使浏览器关闭在工具返回前，桌面端仍可重建会话中的生图卡片。旧浏览器聊天快照不会覆盖已完成的图片。服务端尝试在生成成功后进行原有的最多 256 Token 视觉回复，异常回退为简短完成文本。
- **画廊浏览器重构**：手机沉浸式图片浏览、横屏全屏尝试、双击缩放、双指捏合、放大拖动、还原时左右翻图。部分 iOS 浏览器限制程序化横屏，自动退化为屏幕内沉浸视图。
- **4x 入口**：已有 4x 时显示「原图 / 4x」并默认显示 4x；没有超分版本时显示「生成4x图」。后台排队、生成、完成后仍将原图/4x 作为一组作品。
- **局域网多网卡直连**：Launcher 列出活跃 IPv4 接口，包括 Wi-Fi Direct 移动热点、WLAN、Tailscale 等，而不是只显示一项。

## 任务生命周期说明

- **浏览器或手机断开**：桌面端继续生图、超分及保存，不需要页面轮询保活。
- **桌面服务重启或机器关机**：正在运行或等待的内存队列不跨进程自动续跑，重启后原任务标记为 `interrupted`；完成产物永久保存在 `chat/generated-images`。
- **GPU 资源**：本地生图与独立 4x 使用现有 `gpu_turn` 调度；不会由于独立任务在浏览器端额外开启模型进程。
- **兼容**：保留 OpenAI 兼容的同步 `/v1/images/generations` 接口，第一方 Web UI 改走 `/v1/mikuchin/image-jobs`。保留现有用户数据，不迁移或清空对话。

## 发布/验证

- Windows 启动器需重新编译 EXE 与 NSIS 安装包，并以新的可执行文件替换本机程序。
- Android APK 需按原密钥重新签名，确认 `versionCode=210` 且签名证书与 0.2.9 相同，随后替换本机的 APK 构建产物。
- 发布前通过后端回归、前端 JavaScript 语法、版本一致性及 SHA256 检验。
