# Mikuchin 图片 API 服务改造（2026-11-15）

## 使用

在 Mikuchin「设置 → API 生图服务」里新增服务，填名称、OpenAI Images Base URL、API Key、模型 ID；需要代理时勾选「通过代理访问」并填写完整地址，例如 socks5h://127.0.0.1:7897。根据服务商的能力选择参考图模式（多图/单图/不支持）、尺寸和可选 Seed、Steps、Negative Prompt。然后在「图像 → 生图服务」选择即可。聊天生图可在「设置 → 聊天生图模型」选择 API 服务。

## 模型 ID 自动探测（2026-11-16）

- 在 API 服务弹窗的「模型 ID」旁点击「获取模型」，由后端使用当前输入的 Base URL、API Key 和代理设置请求 `GET <Base URL>/models`。
- 新增服务无需预先保存即可探测；编辑原有服务时可以复用服务器端保存的密钥，但更改 Base URL 后必须明确重新输入 API Key，避免密钥被静默转发到新的目标。
- 支持标准 OpenAI `{data:[{id:...}]}` 模型列表以及部分网关的 `{models:[...]}` 格式。
- 模型按名称和元数据初步分成「可能支持生图」与「其他模型（未验证）」，仅是候选提示，不能凭 `/models` 确认真实生图能力；下拉选中会填入可编辑的模型 ID。
- 不支持 `/models`、返回非标准结构或获取失败时，继续允许手工填写模型 ID；探测不会触发生图、不会保存新服务、不会把 API Key 返回前端。
- 探测接口限定返回 2 MiB 内模型目录；对非成功响应、超时、重定向等错误显示失败原因，不自动转发到新目标。

## 接入机制

- 生图页最多可上传 8 张 PNG、JPEG、WebP 参考图（单张小于 5 MiB），按上传顺序排列，支持置首、移除、清空。服务支持多图时全部使用，仅单图时使用第一张，不支持则全部跳过；切换服务不会删除上传图片。
- 外部 API：标准 POST /v1/images/generations（文生图）以及 /v1/images/edits（参考图编辑）。图片响应接受 base64 或安全的 HTTPS 图片 URL；转换为 PNG 后保存到 chat/generated-images，继续由既有会话显示与管理流程处理。
- 发送给外部服务的只有当前生图提示词、能力支持的参数、选中的参考图片。LoRA、本地超分及本地 GPU 调度不发送给云端。
- 每个 API 服务可单独启用 HTTP、HTTPS、SOCKS5 或 SOCKS5H 代理。SOCKS5H 让代理端完成 DNS 解析。
- 设置记录保存在服务端 config/image-api-services.json（Git 已忽略）；API Key 不回传给浏览器，编辑时留空保留之前的密钥。**该文件的 API Key 目前以普通文本保存在磁盘上，尚未接入 DPAPI 加密。** 请勿共享此配置文件。
- 云端生成会把提示词和被使用的参考图发送给所配置的第三方服务，可能产生费用。参考图能力与参数支持取决于服务商，OpenAI-compatible 不保证所有服务商都兼容图像编辑或扩展参数。
- 2026-11-16 生图服务下拉统一显示为「服务商-[模型 ID]」，不会改变服务商本身的设置名称。
- 运行状态栏可显示当前阶段、客户端实测耗时和本地生图步数；失败时在页面内显示来自后端/服务商的错误说明，已完成请求保留耗时。
- 本地超分选择框移到宽度右侧；API 生图改为「启用 4 倍超分」复选框，默认关闭，不尝试自动判断 2D/3D。开启后由 **Mikuchin 本机** 的 Real-ESRGAN 对 API 返回图片进行超分，不要求 API 提供超分能力。超分失败会保留原图并展示失败原因；成功时同时持久化超分前原图。
- API 模式超分前最长边暂限 1536 像素（超分后最长边 6144 像素）；需本机已配置且启用 Real-ESRGAN。API 本身的输出尺寸限制仍按服务配置处理，不因启用本地超分而改变。
